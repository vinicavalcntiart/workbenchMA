# Projeto de pesquisa

Arquivos esperados aqui, criados conforme o projeto amadurecer:

- `problema.md`: pergunta de pesquisa, objeto e recorte, em uma página.
- `objetivos.md`: objetivo geral e específicos.
- `justificativa.md`: por que isso importa e para quem.
- `metodologia.md`: abordagem, procedimentos, corpus, instrumentos.
- `cronograma.md`: semestre a semestre até a defesa.
- `decisoes.md`: log datado de toda mudança de rumo.
- `projeto-vN.md`: versões do projeto consolidado, entregues ao orientador ou ao programa.
