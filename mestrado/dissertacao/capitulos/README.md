# Capítulos

Um arquivo por capítulo, numerado com dois dígitos:

```
00-resumo.md
01-introducao.md
02-fundamentacao-teorica.md
03-metodologia.md
04-analise.md
05-consideracoes-finais.md
```

Os nomes acima são um esqueleto. Renomeie conforme o sumário real. Versões antigas de um capítulo vão para `capitulos/arquivo/` com sufixo de data.
