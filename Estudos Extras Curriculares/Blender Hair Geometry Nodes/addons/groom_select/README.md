# Groom Select

Seleciona guias de hair curves por atributo, e salva a selecao como atributo.
So mexe na selecao. Nunca move, apaga ou reordena curva.

## Instalar

Preferences > Get Extensions > seta no canto > Install from Disk > `groom_select.zip`.
O painel fica na sidebar (N) do viewport, aba **Groom**.

## Selecionar por atributo

1. Escolha o atributo na lista.
2. **Selecionar** substitui a selecao. **Adicionar**, **Remover** e **So nesses**
   combinam com o que ja esta selecionado.

Bool seleciona as curvas marcadas. Int pede um valor. Float pede uma faixa.
Atributo por ponto conta a curva inteira se qualquer ponto bater.

## Salvar selecao como atributo

1. Selecione guias no viewport.
2. Digite um nome e clique **Substituir**. Vira um atributo booleano por curva,
   pronto para usar em Named Attribute nos nodes.
3. **Adicionar** e **Remover** editam um grupo que ja existe.

## Tudo / Nada / Inverter

Atalho para a selecao inteira, sem sair do painel.
