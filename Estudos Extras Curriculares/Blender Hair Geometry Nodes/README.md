# Blender Hair Geometry Nodes

Estudo de grooming realista com o sistema novo de hair do Blender: objeto
Curves mais os hair nodes de Geometry Nodes da biblioteca Essentials
(Interpolate Hair Curves, Clump Hair Curves, Frizz Hair Curves, Create Guide
Index Map, Hair Dynamics e companhia).

Ponto de partida do estudo: o material oficial do Blender Studio saiu junto com
a versao 3.5, em 2023, e nunca foi atualizado. Os node groups mudaram desde
entao e os arquivos de exemplo nao batem mais.

## Arquivos

- `pesquisa_hair_geonodes.md` — levantamento de tudo que existe de material de
  estudo sobre o tema: cursos, tutoriais, arquivos .blend, packs, palestras,
  threads tecnicas, documentacao, artistas para acompanhar, historico de
  mudancas dos hair nodes por versao e lacunas.
