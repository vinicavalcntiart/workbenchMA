Mesh Hair with Geometry Nodes and Hair Curves
Join Sara Matsumoto as she demonstrates how to create editable mesh hair using hair cards and tubes, and prepare realistic hair textures with Hair Curves. She will then apply these textures to a Geometry Nodes setup. With these techniques, you’ll discover that creating real-time hair is easier than ever, while still retaining grooming edit capabilities!
