## Pontos técnicos (resumo em português)

- Objetivo da técnica: criar cabelo em formato de MALHA (mesh) a partir de Hair Curves com Geometry Nodes, mantendo a possibilidade de continuar penteando (grooming) e animando como se fosse curva — útil para alternar rapidamente entre Cycles (partículas/curvas) e EEVEE (malha) com o mesmo visual, e para exportar personagens em tempo real (jogos).
- Etapa 1 — criar as texturas de cabelo (textura de mecha): criar um plano, extrudar um lado para plantar o cabelo, separar em material próprio e garantir UVs (sem UV o cabelo não gruda na superfície).
- Adicionar objeto "Empty Hair" no retângulo/mecha e usar as ferramentas de grooming (inclusive Snake Hook) para variar comprimento de forma desigual e mais realista; pentear até cobrir todo o quadrado da textura (erro citado pela palestrante: não ter preenchido até as bordas atrapalha depois no encaixe da UV das mesh cards).
- Usar o shader "Principled Hair BSDF" (renomeado na fala de "principal hair") no material do cabelo-guia (para o render das texturas), e material transparente no plano de fundo.
- Aplicar os presets prontos do Asset Browser do Blender (duplicar, clump, curl, profile de espessura raiz/ponta) sobre os fios-guia, camada por camada (uma camada principal + uma segunda camada de fios "soltos"/messy por cima, também com profile de espessura), e node "Blend Hair Curves" para dar aparência mais fofa/separada.
- Deixar um espaço vazio (gap) no centro da textura de mecha de propósito — necessário depois para separar a UV usada pelos "cards" (3 lados) da UV usada pelos "tubos" (6 lados).
- Configurar View Layer/Render Passes para capturar os mapas necessários da mecha renderizada: profundidade (Depth), Normal, Position, Specular/Ambient Occlusion — câmera ortográfica quadrada enquadrando exatamente a mecha.
- Ajustar o mapa de profundidade com um node RGB Curves (fica todo branco por padrão) para revelar a diferença entre fios da frente e de trás.
- Etapa 2 — montar o shader da mecha final (mesh) usando Principled BSDF comum (não o Principled Hair): Base Color e Alpha vindos das texturas renderizadas; Normal Map + Bump (combinando o mapa de altura) para relevo; Roughness construído a partir da textura em preto e branco ajustada com RGB Curves (evita look "plástico" uniforme); Metallic para reflexo; e o mapa de Position ligado ao "Anisotropic Tangent" para dar o brilho alongado (anisotropia) característico de cabelo real em vez de um brilho redondo.
- Sistema de coloração por camadas com Mix Color (RGB Mix): uma máscara de Ambient Occlusion controla realces/highlights (Color Ramp ajusta intensidade), e uma segunda máscara com Texture Coordinate (vertical) + Color Ramp controla a cor da raiz por cima (para simular raiz de cor diferente da make/mechas tingidas).
- Etapa 3 — construir a malha real em Geometry Nodes ("hair mesh"): Resample Curve primeiro (corrige ordem de vértices bagunçada por ferramentas como Snake Hook); depois Curve to Mesh usando um node "Arc" de poucos lados (ex. 3, tipo "meio-tubo") como perfil — evitado o perfil circular fechado por gerar artefatos.
- Node "Curve Tangent" ligado ao "Tilt" da curva para que cada card/fio se oriente automaticamente seguindo a superfície esculpida (em vez de cada fio apontar para uma direção aleatória).
- Alternativa "tubo" com o node "Spiral" (ajustando Start Radius = End Radius via um valor constante compartilhado, Height = 0, Resolution baixa, Rotations = 1) para gerar um tubo fechado sem os artefatos do perfil circular fechado do Curve to Mesh; um node Switch alterna entre Cards (3 lados, leve) e Tubes (6 lados, mais denso) conforme a necessidade de detalhe/close-up vs. distância.
- Clumping da malha: usar "Set Radius" ligado a uma RGB Curve controlada pelo fator de Spline Parameter, permitindo desenhar a forma do afunilamento (clump) igual ao que se fazia com modificadores de cabelo tradicionais — o mesmo valor de clump é reaproveitado tanto para cards quanto para tubes para manter a espessura consistente entre os dois modos.
- Criação manual de UVs dentro de Geometry Nodes (etapa mais trabalhosa da palestra): dois "Capture Attribute" (um para o comprimento/Spline Parameter do fio, outro para a largura da forma extrudada), combinados com "Separate XYZ" (Y = comprimento do fio, X = largura do perfil) e gravados com "Store Named Attribute" (tipo Vector, nome "UVs"); é preciso também expor esse atributo como output do grupo de nodes com o mesmo nome para que o node UV Map do shader o enxergue.
- Ajustes finos de UV: inverter direção multiplicando por -1 (raiz/ponta trocadas); como o shader não aceita um Vector diretamente na Color Ramp, converter o vetor em fator escalar usando um node "Gradient Texture" e rotacionar 90° a "Mapping" (a UV nasce de lado, precisa ficar de cima para baixo); "Invert Color" para corrigir a direção final.
- Correção de densidade entre cards (3 lados) e tubes (6 lados) usando a mesma textura: como o perfil de 3 lados comprime a textura (dobro de densidade aparente), foi preciso gerar uma segunda UV "cortada pela metade" (Vector Math > Multiply, X=0.5, Y=1) especificamente para os cards, comutada pelo mesmo Switch que alterna cards/tubes — por isso o gap deixado no centro da textura foi útil.
- Fixação da raiz na superfície esculpida ("root attachment"): usar a UV (Separate XYZ) + Object Info (objeto do couro cabeludo) + Geometry Proximity + Position, selecionando apenas os pontos onde Y=0 (raiz) via node "Equal" (com margem de Epsilon ajustável) para colar só a raiz na superfície e deixar o resto do fio livre para pentear.
- Organização final do node group: expor no modificador os parâmetros úteis para o usuário final — Switch (cards/tubes, ligado também ao switch da UV cortada), Tube Tilt (multiplicador para ajustar só a orientação dos tubos, já que os cards já são resolvidos pela tangente), nível de Subdivisão (evita aparência "quadrada" em close-up) e um input para o objeto "scalp"/superfície de encaixe (reutilizável em outros personagens, ou até em grama).
- Resultado final continua editável com as MESMAS ferramentas de grooming e os MESMOS assets/modificadores usados em Hair Curves normais (interpolar, encaracolar/curl, duplicar) mesmo sendo malha "de verdade"; ressalva: ao interpolar geometria de malha, a escala do objeto precisa ser bem grande (ordem de milhões) para o efeito aparecer corretamente.
- Comparação de performance/uso relatada pela palestrante: ela passou a preferir cabelo em malha (mesh) a cabelo em curvas para renderizar personagens completos, por achar as curvas mais instáveis e o mesh mais controlável e rápido de renderizar (exemplos citados: ~3 min/frame em alta resolução, ~1 min/frame em resolução menor, com centenas de frames, no character creator "Transhuman").
