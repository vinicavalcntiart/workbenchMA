## Pontos técnicos (resumo em português)

- Fluxo geral: usar uma "hair cap" (malha de crescimento separada da malha da cabeça) para não depender da topologia/densidade do personagem; a hair cap é o objeto de superfície ("surface") referenciado pelos modificadores de cabelo.
- Usar um grupo de vértices (vertex group) marcando a linha do cabelo/repartição ("parting") e uma edge dura (hard edge) para dividir a malha em duas metades — facilita a interpolação do cabelo depois.
- Fluxo de criação manual: selecionar a hair cap → Curve > Add Empty Hair → Sculpt Mode; usar os pincéis Add, Density, Comb, Snake Hook, Puff, Smooth, Slide, Pinch para esculpir os guias de cabelo.
- No pincel Comb/projeção, ativar o modo "Projected" (em vez de esférico) para pentear corretamente áreas de trás sem serem bloqueadas pela câmera/esfera de influência.
- "Scale Uniform" desligado é preferível: faz o cabelo continuar na direção existente em vez de escalar a partir da raiz.
- Seleção por pintura (Paint Selection): mudar o modo de seleção para "Curve" (em vez de pontos) para selecionar fios inteiros; útil para "flood fill" de comprimento e depois reajustar.
- Antes de esculpir, aumentar a resolução dos guias com o node "Resample Curve" (ex.: 15 pontos) e aplicar como modificador para permitir formas mais detalhadas.
- Em Render Properties > Curves, mudar o modo de "Strand" para "Strip" e adicionar subdivisões para o cabelo ter espessura real e exibir corretamente no viewport.
- Usar o modificador "Shrink Wrap Hair Curves" para evitar interseção do cabelo com a malha: ajustar "Above Surface" para 0 e ativar "Offset" com uma distância, empurrando pontos internos para fora da superfície.
- Setup procedural principal (Geometry Nodes) construído com os nodes: Hair Curves Noise (ruído com "Offset Per Curve" ligado para variar por fio, e escala reduzida ao longo da curva para preservar o comprimento), Roll Hair Curves (curvatura na ponta do fio, imitando cabelo real que não termina reto) e orientação randomizada.
- Node "Interpolate Hair Curves": precisa de inputs de superfície (surface) e mapa UV da superfície (surface UV map) vindos do Group Input, ligados no modificador à hair cap e ao UV map correspondente.
- Node "Hair Curve Profile" controla a espessura da raiz à ponta via parâmetro "Shape": valor 1 afeta só a ponta, perto de 0 afeta a curva inteira, valores negativos afetam mais a raiz.
- Node "Clump Hair Curves" cria tufos (clumps); parâmetro "Guide Distance" controla quantos clumps surgem proceduralmente (raio maior = menos clumps); pode-se usar guias explícitas em vez de distância. Duas camadas de clumps foram criadas: "wide clumps" (grossos) e camada fina, cada uma com seu próprio ruído/seed para variar a forma e evitar sobreposição idêntica.
- Uso de textura de densidade pintada (branco = cabelo denso, cinza 50% = densidade base, preto = sem cabelo) ligada ao "Density Mask" do Interpolate Hair Curves via nó Image Texture + Named Attribute (UV map) + Color Ramp (ponto de corte logo acima de 0.5) para resolver calvície na área da repartição.
- Parâmetro de densidade global exposto no modificador (multiplicador "Global Density" x densidade por camada) para reduzir tudo de uma vez quando a cena fica pesada.
- Uso de "Store Named Attribute" para colorir por camada (clump largo = vermelho, fino = amarelo etc.) apenas para depuração visual no viewport (via atributo lido no shader), facilitando ver a mistura das camadas ao usar Join Geometry.
- Correção da repartição central (parting): copiar a malha de crescimento, apagar tudo exceto a linha central (via peso/weight paint "Parting Center" lido com Named Attribute + Delete Geometry), depois usar "Mix"/blend para colar as raízes próximas da linha central diretamente nela, evitando falhas visíveis na risca.
- Para dar volume/levantar o cabelo perto da risca: node "Deform Curves on Surface" (hair curves) usando "Surface Normal Displacement", combinado com Geometry Proximity (Target = linha central, modo Edges) + Map Range + Float Curve para mapear distância da risca em uma curva de fator (criando o "monte" suave na base do cabelo sem afetar as raízes exatas).
- Padrão de trabalho recorrente do artista: manter setups pequenos em "Frames" nomeados (Shift+P) dentro da árvore de nodes para organizar wide clumps, density, etc.
