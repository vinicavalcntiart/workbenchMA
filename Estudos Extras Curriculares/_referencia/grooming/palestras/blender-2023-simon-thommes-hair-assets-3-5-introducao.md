## Pontos técnicos (resumo em português)

- Blender 3.5 introduz uma biblioteca de node group assets ("Essentials") voltada a um fluxo de grooming procedural de cabelo, construída inteiramente sobre Geometry Nodes.
- Aviso importante do próprio Blender (2023): o objetivo é substituir o sistema antigo de partículas/cabelo por completo, mas nesta versão o foco é só em casos de uso estáticos — simulação/Hair Dynamics ainda não estava disponível (ficou para versão futura).
- O sistema novo não exige conhecimento de nodes: dá para usar tudo via interface de modificadores (Modifier Stack) empilhando os assets como modificadores comuns.
- Para quem quer mais controle, os mesmos node groups podem ser usados diretamente na Geometry Nodes Editor.
- Os node group assets ficam no Asset Browser, na biblioteca "Essentials", e também aparecem no menu Add > Hair de qualquer editor de Geometry Nodes.
- Subcategorias de nodes de cabelo: Deformation (operações que deformam curvas individuais), Generation (criam novas curvas do zero ou a partir de uma base), Guides (fluxo baseado em curvas-guia que deformam as demais), Read (leem dados da curva de cabelo dentro do setup de nodes), Utility (operações utilitárias gerais) e Write (atualmente só contém a operação de definir espessura via perfil/profile).
- Por serem blocos modulares independentes (em vez de um único node gigante com todos os parâmetros, como no sistema antigo de partículas), dá para empilhar quantos forem necessários, em qualquer ordem que fizer sentido para o caso de uso.
- Fluxo a partir de grooming manual existente: arrastar os assets do Asset Browser diretamente sobre o objeto de curvas no viewport 3D — eles entram como modificadores no stack.
- Alguns modificadores (ex. "Interpolate Hair Curves") exigem que se defina o objeto de superfície (surface) e o mapa UV para funcionar — equivalente ao antigo fluxo de "interpolated children" do sistema de partículas.
- Fluxo para começar do zero: operador "Quick Fur" (Add > Curves), aplicado ao objeto de superfície ativo — inunda a malha com curvas de cabelo novas; parâmetros básicos ajustáveis no painel "redo" (F9).
- Conceito central de "guide maps": ao usar interpolação, já existe um conjunto de curvas-guia selecionadas para cada curva; operações subsequentes (clumping, curling, tranças/braiding) usam automaticamente esse guide map.
- No Curve Sculpt Mode dá para ver a sobreposição das curvas-guia originais; movê-las atualiza automaticamente os clumps que dependem delas.
- Para não depender do guide map anterior, é possível desativar o toggle "existing guide map" e criar um novo guide map na hora; esse novo guia se propaga para as operações seguintes na pilha.
- Node/modificador "Create Guide Index Map" dá controle mais granular sobre o mapeamento de guias, permitindo múltiplas camadas de clumping com diferentes níveis de granularidade.
- Operador "Move to Nodes": converte um modificador simples do stack em uma árvore de node group própria (envolvendo o node original), permitindo conectar entradas customizadas quando o fluxo de modificador simples não é flexível o suficiente — fluxo recomendado: começar simples com modificadores, migrar para nodes só quando precisar de mais controle.
- Como tudo é baseado no novo tipo de dados "Hair Curves", em qualquer ponto dá para aplicar o modificador e obter geometria real (curvas "aplicadas"), permitindo ajustes manuais finais que não são possíveis proceduralmente.
- Por padrão as curvas de cabelo se deformam junto com a superfície subjacente (deformação estática acompanhando a malha), mas Hair Dynamics completo (simulação física) ainda não era suportado nesta versão (3.5).
