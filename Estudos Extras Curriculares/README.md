# Estudos Extras Curriculares

Pasta de estudo técnico fora do trabalho de campanha e portfólio. Cada tema tem
sua própria subpasta, com a pesquisa e os materiais de apoio dentro dela.

## Temas

- `Blender Hair Geometry Nodes/` — grooming realista com o sistema novo de hair
  do Blender (objeto Curves + hair nodes de Geometry Nodes). Pesquisa de
  material de estudo, arquivos para engenharia reversa e histórico de mudanças
  dos nodes por versão.
- `_referencia/` — copia em texto do manual do Blender 5.2 LTS e da
  referencia da API Python 5.2, para consulta offline. Ver o README de la.
